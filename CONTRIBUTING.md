# Contributing

Thanks for your interest in contributing to Agentic Research Intelligence.

## Local setup

1. Create and activate a virtual environment using Python 3.11.
2. Install dependencies from `requirements.txt`.
3. Run the test suite before submitting a pull request.

## Workflow

- Keep changes focused and documented.
- Prefer small, reviewable pull requests.
- Use clear commit messages.
- Add or update tests for behavior changes.
- Run Ruff and pytest locally before opening a PR.

## Code style

- Follow PEP 8 and Ruff defaults.
- Keep business logic in service modules when appropriate.
- Prefer environment-based configuration for settings.
- Avoid logging secrets or sensitive user data.
